arc-rclone privacy policy

Effective 17 October 2026.

arc-rclone is a private backup tool with one user: the owner of the Google account it is connected to. It runs on that owner's own computer. This policy describes how it handles Google user data.

What it accesses

arc-rclone requests the Google Drive drive.file permission. With it, the tool can see and change only the files that arc-rclone itself creates in the owner's Drive. It cannot read, list, or change any other files in that Drive.

How it uses the data

It uses that access for one thing only: storing and reading the owner's backup files. Before upload, the backup is encrypted on the owner's computer with restic. The encryption key never leaves the owner's control.

Where data is stored

Backup files are stored only in the owner's own Google Drive. The sign-in token for Google is stored only on the owner's computer. arc-rclone runs no servers and stores no data anywhere else.

Sharing

arc-rclone does not share, sell, or transfer Google user data to anyone. It does not use the data for advertising, analytics, or training AI or machine-learning models.

Revoking access

The owner can revoke arc-rclone's access at any time at myaccount.google.com/permissions. Deleting the backup files from Drive removes the stored data.
